# Contributing to Local R2 Drive

First off, thank you for considering contributing to Local R2 Drive! It\'s people like you that make the open-source community such a great place to learn, inspire, and create.

## ?? Code of Conduct
By participating in this project, you agree to abide by our Code of Conduct. (In short: Be kind, professional, and respectful.)

## ?? How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issue Tracker.
- Describe the bug in detail, including steps to reproduce and your environment (Node.js version, OS, etc.).

### Suggesting Enhancements
- Check if the feature has already been suggested.
- Open an issue with a "Feature Request" label.
- Explain why this enhancement would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you\'ve added code that should be tested, add tests!
3. Ensure the test suite passes.
4. Issue that pull request!

## ?? Local Development Setup
1. Clone your fork.
2. Run `npm run install:all`.
3. Create your `.env` file.
4. Run `npm run dev`.

## ?? Style Guide
- We use **TypeScript** for both frontend and backend.
- **Frontend**: Follow the existing component structure in `src/components`. Use Tailwind CSS for styling.
- **Backend**: Keep controllers thin and logic in services.
- Use meaningful variable names and add comments for complex logic.

Thank you for your contributions!
